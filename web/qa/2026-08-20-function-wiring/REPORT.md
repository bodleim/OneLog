## 수정 범위

- 브라우저 로컬 영속 상태를 식단, 찜, 재고, 장보기, 요리 완료, 나눔 채팅, 알림 설정의 단일 상태로 통합했다.
- 1~7일 기간, 날짜별 아침·점심·저녁, 직접 입력 예산, 식단안 선택·직접 교체·AI 후보 적용을 실제 최종 식단으로 전달한다.
- 식단 재료 합산, 판매 단위 구매량, 예상 금액·예산 초과, 부분 구매 반영, 구매 재고 추가, 계획 수량 요리 차감과 중복 완료 방지를 결정론적 함수로 분리했다.
- 주간 식단의 미루기·교체·비활성화·삭제가 식단과 장보기 목록을 다시 계산한다.
- 소분 요청 생성·취소, 채팅 메시지, 알림 읽음·알림 설정을 화면을 닫거나 다시 열어도 유지한다.
- AI Route Handler는 선호·알레르기·요청 문장의 `없이/빼고/제외` 재료를 후보에서 제거하며 `계란↔달걀` 동의어를 처리한다. AI는 후보 ID만 반환하고 금액·수량 계산에는 관여하지 않는다.

- 웹 앱 상태는 이 브라우저에 저장되며 iOS UserDefaults 또는 Firebase 식단 데이터와 자동 동기화하지 않는다.

- 웹 소분·채팅의 이번 연결은 브라우저 로컬 영속 상태다. 서로 다른 두 기기의 Firebase 실시간 나눔·채팅 검증은 iOS와 동일하게 남아 있다.
